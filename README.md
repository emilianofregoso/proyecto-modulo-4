## Descripción del proyecto
Programa en Python que registra las calificaciones de un grupo de alumnos y calcula estadísticas del grupo.

El programa:
- Usa una clase `Alumno` con nombre, matrícula y calificaciones (lista de enteros), y un método `promedio()`.
- Guarda a los alumnos en una **lista**.
- Guarda las calificaciones en una **matriz** (lista de listas): cada fila es un alumno y cada columna una calificación.
- Pide los datos al usuario con `input()`.
- Muestra los resultados con `print()` y f-strings:
  - Promedio de cada alumno.
  - Promedio mayor, promedio menor y promedio general del grupo.
  - Promedio del grupo por cada calificación.
